# Questify – Android-Downloads

Hier liegen die Android-Builds (APK) der Questify-App.

**Neueste Version:** [questify.apk](https://github.com/vassiljevnikita-sudo/questify-releases/releases/latest/download/questify.apk)

Installation: APK auf dem Android-Gerät öffnen und „Installation aus unbekannten Quellen“ für den Browser erlauben.
Updates: neue APK einfach über die alte installieren; die Daten liegen auf dem Server und bleiben erhalten.

Web-Version: https://mastertasker.expo.app

Jede Release-Seite nennt die Prüfsumme (SHA-256) der APK.
